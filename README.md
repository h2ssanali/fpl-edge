# ARKILO — ميزتك على دوريك المصغّر

مساعد فانتازي الدوري الإنجليزي (FPL) مجاني بالكامل إلى الأبد: موقع ثابت على GitHub Pages، وبيانات تُحدَّث تلقائياً عبر GitHub Actions. لا خوادم، لا مفاتيح API، لا اشتراكات.

**الرابط:** https://h2ssanali.github.io/fpl-edge/

---

## ما الذي يقدمه؟

**محرك توقعات شفاف** (`src/engine/`) يجمع لكل لاعب ولكل مباراة:
احتمال المشاركة والدقائق (البدايات الأخيرة، `chance_of_playing`، الأخبار، المداورة) · xG وxA لكل 90 دقيقة · قوة الخصم (نموذجنا الخاص من xG مع/ضد لأن حقول القوة في FPL أصبحت صفراً هذا الموسم) · احتمال الشباك النظيفة · احتمال البونص من تاريخ BPS · المساهمة الدفاعية · قواعد التسجيل حسب المركز · الجولات المزدوجة والفارغة.

ثم **محاكاة مونت كارلو 10,000 مرة** لكل جولة داخل Web Worker: نتيجة كل مباراة تُسحب أولاً ثم تُوزَّع الأهداف والتمريرات على اللاعبين، فيكون زملاء الفريق مترابطين (فوز 4-0 يرفع الدفاع والهجوم معاً). النتيجة توزيعات كاملة لا أرقام مفردة: احتمال التسجيل والصناعة والشباك النظيفة و+10 نقاط، والوسيط وأسوأ/أفضل 10٪ للاعب وللتشكيلة كاملة. وكل توصية معها **السبب بالعربية** («ضد LEE (أرض) · 0.62 xG/90 · احتمال البداية 91٪»).

**الميزات الأساسية:** اختيار الكابتن (آمن/مغامرة) · مخطط انتقالات لست جولات بالسحب والإفلات مع الرصيد والانتقالات المجانية والقيمة الحقيقية لخصم −4 · مُحسِّن يقترح أفضل 1 أو 2 أو 3 انتقالات · رادار الأسعار · اللاعبون المختلفون · جدول صعوبة 8 جولات · مخطط الشرائح · الفريق الحلم · الإصابات والتشكيلة · تقرير الجولة.

**ميزات لا توجد في أي تطبيق آخر:**
- **حمض الخصوم (Rival DNA):** أسلوب كل منافس في الكابتن، الخصومات، مطاردة المتألقين، توقيت الشرائح، والرصيد — مع توقع كابتنه وانتقالاته القادمة و«كيف تتفوق عليه».
- **مؤشر المخاطرة:** التوصيات تتغير حسب موقعك؛ في الصدارة «حماية» وفي المطاردة «هجوم»، مع احتمال فوزك بالدوري وأثر كل انتقال عليه.
- **الملكية الفعلية في دوريك وسيناريوهات «ماذا لو»:** «إن أخفق هالاند ستكون الثاني، وإن تألق ستكون الخامس».
- **محرك الأثر الرجعي:** لو اتبعت ARKILO طوال الموسم كم نقطة وترتيباً كنت ستحقق، وأين أخطأ النموذج.
- **سجل القرارات:** تقييم جودة القرار بمعزل عن الحظ («قرار جيد، حظ سيئ»).
- **مؤشر الفوضى:** متى تلعب بأمان ومتى تغامر.
- **بطاقات ستوري 9:16** مصممة للريلز والستوري بلمسة واحدة.
- **وضع الموعد النهائي:** عد تنازلي وقائمة تحقق أخيرة واحتمال دخول كل بديل.

## إضافة فريقك — من داخل التطبيق مباشرة

افتح التطبيق، وفي الخانة أعلى الصفحة (أو **المزيد ← الإعدادات**) اكتب رقم فريقك واضغط **«اعرض فريقي»**. يمكنك أيضاً لصق رابط فريقك من موقع FPL كاملاً.

- **أين أجد الرقم؟** موقع FPL ← «النقاط» (Points)، الرقم بعد `/entry/` في الرابط، مثلاً `https://fantasy.premierleague.com/entry/1234567/event/9` ← `1234567`.
- يُحفظ اختيارك على جهازك، ويمكنك اختيار دوريك المصغّر من القائمة إن كان لديك أكثر من دوري.
- **شارك التطبيق مع أصدقائك:** زر «انسخ رابطاً لفريقي» ينشئ رابطاً مثل `https://h2ssanali.github.io/fpl-edge/?team=1234567`. وأي شخص يفتح الموقع يستطيع كتابة رقم فريقه بنفسه.
- يظهر تحليل فريقك خلال ثوانٍ، ثم يُحمَّل الدوري المصغّر والخصوم في الخلفية (دقيقة أو دقيقتان في أول مرة، وبعدها من الذاكرة).

**كيف يعمل؟** موقع FPL لا يسمح للمتصفحات بقراءة بياناته مباشرة، لذلك تُجلب بيانات الفريق عبر وسيط مجاني (r.jina.ai) يسمح بنحو 20 طلباً في الدقيقة لكل زائر. بيانات اللاعبين والمباريات تأتي دائماً من الملفات التي يحدّثها GitHub Actions.

### (اختياري) وسيط خاص أسرع وأكثر ثباتاً — 5 دقائق ومجاني

الوسيط المجاني العام قد يتوقف أو يبطئ. لتحميل أسرع بلا حدود عملية:

1. أنشئ حساباً مجانياً على [Cloudflare](https://dash.cloudflare.com/sign-up) (لا يحتاج بطاقة).
2. **Workers & Pages ← Create ← Create Worker**، سمّه مثلاً `fpl-edge-relay` ثم **Deploy**.
3. **Edit code**، احذف المحتوى والصق محتوى الملف [`relay/worker.js`](relay/worker.js)، ثم **Deploy**.
4. انسخ رابط الـ Worker (مثل `https://fpl-edge-relay.yourname.workers.dev`) وضعه في `config.json` في الحقل `relayUrl`.

الوسيط يقبل فقط عناوين FPL العامة للقراءة، والخطة المجانية تسمح بـ100,000 طلب يومياً.

## إعداد فريق افتراضي للموقع (اختياري)

إن أردت أن يفتح الموقع على فريقك لكل زائر لم يُدخل رقمه، وأن يُحدَّث فريقك ودوريك تلقائياً على الخادم، ضع الأرقام في [`config.json`](https://github.com/h2ssanali/fpl-edge/edit/main/config.json):

<div dir="ltr">

```json
{
  "teamId": "1234567",
  "leagueIds": [123456],
  "relayUrl": ""
}
```

</div>

حفظ الملف على GitHub يشغّل تحديث البيانات وإعادة النشر تلقائياً. يمكنك بدلاً من ذلك تشغيل [Actions ← Refresh FPL data](https://github.com/h2ssanali/fpl-edge/actions/workflows/data.yml) ← **Run workflow** مع `team_id` و`league_ids`. وإن تركت الدوريات فارغة نكتشف دورياتك الخاصة تلقائياً. بدون أي إعداد يعمل الموقع في **الوضع التجريبي** على متصدّر الترتيب العام.

## كيف تعمل التحديثات؟

واجهة FPL الرسمية لا تسمح للمتصفح باستدعائها مباشرة (لا يوجد CORS)، لذلك:

1. سير العمل `.github/workflows/data.yml` يجلب البيانات من `fantasy.premierleague.com/api` بأدب (طلبات محدودة ومتباعدة مع إعادة المحاولة)، ويكتب ملفات JSON مضغوطة في `public/data/`، ثم يحفظها في المستودع ويعيد نشر الموقع.
2. الجدول: **كل 6 ساعات**، و**كل ساعة في يوم الموعد النهائي**، ويمكن تشغيله يدوياً في أي وقت.
3. يُحفظ سجل يومي للأسعار والملكية في `public/data/history/` لتعمل الاتجاهات ورادار الأسعار.
4. الجولات المنتهية تُخزَّن ولا تُجلب مرة أخرى.
5. الموقع **تطبيق PWA**: أضفه إلى الشاشة الرئيسية من المتصفح، ويعمل دون اتصال بآخر بيانات محفوظة.

كل دفعة إلى `main` تبني الموقع وتنشره عبر `.github/workflows/deploy.yml`.

## التحكم بمن يدخل الموقع (رموز الدعوة)

بدون إعداد يبقى الموقع مفتوحاً للجميع. لتجعله للمدعوين فقط:

1. افتح المستودع على GitHub ← **Settings** ← **Secrets and variables** ← **Actions** ← **New repository secret**.
2. الاسم: `ACCESS_CODES`. القيمة: شخص في كل سطر، الاسم ثم نقطتان ثم الرمز:

<div dir="ltr">

```
Hassan: ARK-HASSAN-2026
Ahmad: AHMAD-7731
Omar: OMAR-4410
```

</div>

3. اضغط **Add secret**، ثم من **Actions ← Deploy to GitHub Pages ← Run workflow** أعد النشر (أو انتظر التحديث التلقائي التالي خلال 6 ساعات).

- **إضافة شخص:** عدّل الـ Secret (زر Update) وأضف سطراً، ثم أعد النشر.
- **إلغاء شخص:** احذف سطره وأعد النشر، فيُطلب منه الرمز من جديد في زيارته التالية ولا يستطيع الدخول.
- **إيقاف الحماية:** احذف الـ Secret وأعد النشر.
- **رابط يدخل مباشرة:** أرسل `https://h2ssanali.github.io/arkilo/?code=AHMAD-7731` فيدخل صاحبه بدون كتابة الرمز.
- الرموز لا تفرق بين الأحرف الكبيرة والصغيرة ولا تهتم بالمسافات.
- الرموز لا تُنشر أبداً: يُنشر فقط «بصمة» مشفّرة لها.
- هذه حماية تمنع الزائر العادي، لا مبرمجاً مصمماً على الدخول، لأن ملفات البيانات نفسها عامة.

## تغيير رابط الموقع

الرابط يتبع اسم المستودع تلقائياً: `https://h2ssanali.github.io/<اسم المستودع>/`. لتغييره إلى `arkilo`:
**Settings ← General ← Repository name** ← اكتب `arkilo` ← **Rename**، ثم أعد النشر من **Actions ← Deploy to GitHub Pages ← Run workflow**. الرابط القديم يتوقف بعدها.

## التشغيل محلياً (للمطورين)

<div dir="ltr">

```bash
npm install
npm run data      # يجلب البيانات (يحتاج اتصالاً بموقع FPL)
npm run dev       # http://localhost:5173/fpl-edge/
npm test          # اختبارات المحرك (Vitest)
npm run build
```

</div>

**البنية:** Vite + React + TypeScript · المحرك في `src/engine/` (نموذج الفرق، ملفات اللاعبين، التوقعات، مونت كارلو، المُحسِّن، الفريق الحلم، الدوري والاستراتيجية، حمض الخصوم، الشرائح، الأثر الرجعي) · العامل `src/worker/` · الشاشات `src/screens/` · جلب البيانات `scripts/fetch-data.mjs`.
