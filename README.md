# FPL Edge — ميزتك على دوريك المصغّر

مساعد فانتازي الدوري الإنجليزي (FPL) مجاني بالكامل إلى الأبد: موقع ثابت على GitHub Pages، وبيانات تُحدَّث تلقائياً عبر GitHub Actions. لا خوادم، لا مفاتيح API، لا اشتراكات.

**الرابط:** https://h2ssanali.github.io/fpl-edge/

---

## ما الذي يقدمه؟

**محرك توقعات شفاف** (`src/engine/`) يجمع لكل لاعب ولكل مباراة:
احتمال المشاركة والدقائق (البدايات الأخيرة، `chance_of_playing`، الأخبار، المداورة) · xG وxA لكل 90 دقيقة · قوة الخصم (نموذجنا الخاص من xG مع/ضد لأن حقول القوة في FPL أصبحت صفراً هذا الموسم) · احتمال الشباك النظيفة · احتمال البونص من تاريخ BPS · المساهمة الدفاعية · قواعد التسجيل حسب المركز · الجولات المزدوجة والفارغة.

ثم **محاكاة مونت كارلو 10,000 مرة** لكل جولة داخل Web Worker: نتيجة كل مباراة تُسحب أولاً ثم تُوزَّع الأهداف والتمريرات على اللاعبين، فيكون زملاء الفريق مترابطين (فوز 4-0 يرفع الدفاع والهجوم معاً). النتيجة توزيعات كاملة لا أرقام مفردة: احتمال التسجيل والصناعة والشباك النظيفة و+10 نقاط، والوسيط وأسوأ/أفضل 10٪ للاعب وللتشكيلة كاملة. وكل توصية معها **السبب بالعربية** («ضد LEE (أرض) · 0.62 xG/90 · احتمال البداية 91٪»).

**الميزات الأساسية:** اختيار الكابتن (آمن/مغامرة) · مخطط انتقالات لست جولات بالسحب والإفلات مع الرصيد والانتقالات المجانية والقيمة الحقيقية لخصم −4 · مُحسِّن يقترح أفضل 1 أو 2 أو 3 انتقالات · رادار الأسعار · اللاعبون المختلفون · جدول صعوبة 8 جولات · مخطط الشرائح · الفريق الحلم · الإصابات والتشكيلة · تقرير الجولة.

**ميزات لا توجد في أي تطبيق آخر:**
- **حمض الخصوم (Rival DNA):** أسلوب كل منافس في الكابتن، الخصومات، مطاردة المتألقين، توقيت الشرائح، والرصيد — مع توقع كابتنه وانتقالاته القادمة و«كيف تتفوق عليه».
- **مؤشر المخاطرة:** التوصيات تتغير حسب موقعك؛ في الصدارة «حماية» وفي المطاردة «هجوم»، مع احتمال فوزك بالدوري وأثر كل انتقال عليه.
- **الملكية الفعلية في دوريك وسيناريوهات «ماذا لو»:** «إن أخفق هالاند ستكون الثاني، وإن تألق ستكون الخامس».
- **محرك الأثر الرجعي:** لو اتبعت FPL Edge طوال الموسم كم نقطة وترتيباً كنت ستحقق، وأين أخطأ النموذج.
- **سجل القرارات:** تقييم جودة القرار بمعزل عن الحظ («قرار جيد، حظ سيئ»).
- **مؤشر الفوضى:** متى تلعب بأمان ومتى تغامر.
- **بطاقات ستوري 9:16** مصممة للريلز والستوري بلمسة واحدة.
- **وضع الموعد النهائي:** عد تنازلي وقائمة تحقق أخيرة واحتمال دخول كل بديل.

## إعداد رقم فريقك (مهم)

بدون إعداد، يعمل الموقع في **الوضع التجريبي** على فريق متصدّر الترتيب العام، ويظهر شريط يشرح كيفية الإعداد.

**1) اعرف رقم فريقك:** افتح موقع FPL ← «النقاط» (Points). الرقم في الرابط بعد `/entry/` هو رقم فريقك، مثلاً:
`https://fantasy.premierleague.com/entry/1234567/event/9` ← رقمك `1234567`.

**2) اعرف رقم دوريك المصغّر (اختياري):** افتح الدوري في موقع FPL؛ الرقم بعد `/leagues/` هو رقمه. إن تركته فارغاً سنكتشف دورياتك الخاصة تلقائياً (حتى 3 دوريات).

**3) ضع الأرقام بإحدى طريقتين:**

- **الطريقة أ — تعديل `config.json` على GitHub:** افتح [config.json](https://github.com/h2ssanali/fpl-edge/edit/main/config.json)، ضع القيم ثم اضغط Commit:

<div dir="ltr">

```json
{
  "teamId": "1234567",
  "leagueIds": [123456]
}
```

</div>

- **الطريقة ب — تشغيل سير العمل:** افتح [Actions ← Refresh FPL data](https://github.com/h2ssanali/fpl-edge/actions/workflows/data.yml) ← **Run workflow**، واكتب رقمك في `team_id` (وأرقام الدوريات مفصولة بفواصل في `league_ids`). يُحفظ ما تكتبه في `config.json` تلقائياً.

بعد التعديل شغّل سير العمل مرة (الطريقة ب تفعل ذلك تلقائياً) وانتظر دقيقتين إلى خمس دقائق حتى يُعاد نشر الموقع.

## كيف تعمل التحديثات؟

واجهة FPL الرسمية لا تسمح للمتصفح باستدعائها مباشرة (لا يوجد CORS)، لذلك:

1. سير العمل `.github/workflows/data.yml` يجلب البيانات من `fantasy.premierleague.com/api` بأدب (طلبات محدودة ومتباعدة مع إعادة المحاولة)، ويكتب ملفات JSON مضغوطة في `public/data/`، ثم يحفظها في المستودع ويعيد نشر الموقع.
2. الجدول: **كل 6 ساعات**، و**كل ساعة في يوم الموعد النهائي**، ويمكن تشغيله يدوياً في أي وقت.
3. يُحفظ سجل يومي للأسعار والملكية في `public/data/history/` لتعمل الاتجاهات ورادار الأسعار.
4. الجولات المنتهية تُخزَّن ولا تُجلب مرة أخرى.
5. الموقع **تطبيق PWA**: أضفه إلى الشاشة الرئيسية من المتصفح، ويعمل دون اتصال بآخر بيانات محفوظة.

كل دفعة إلى `main` تبني الموقع وتنشره عبر `.github/workflows/deploy.yml`.

## التشغيل محلياً (للمطورين)

<div dir="ltr">

```bash
npm install
npm run data      # يجلب البيانات (يحتاج اتصالاً بموقع FPL)
npm run dev       # http://localhost:5173/fpl-edge/
npm test          # اختبارات المحرك (Vitest)
npm run build
```

</div>

**البنية:** Vite + React + TypeScript · المحرك في `src/engine/` (نموذج الفرق، ملفات اللاعبين، التوقعات، مونت كارلو، المُحسِّن، الفريق الحلم، الدوري والاستراتيجية، حمض الخصوم، الشرائح، الأثر الرجعي) · العامل `src/worker/` · الشاشات `src/screens/` · جلب البيانات `scripts/fetch-data.mjs`.

إن لم يظهر الموقع بعد أول نشر: **Settings ← Pages ← Build and deployment ← Source: GitHub Actions**، ثم أعد تشغيل سير العمل «Deploy to GitHub Pages».
